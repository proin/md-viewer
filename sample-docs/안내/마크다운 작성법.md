# 마크다운 작성법

기호를 사용해 제목, 목록, 표, 코드와 링크를 작성합니다.

## 제목과 문단

`#` 뒤에 공백을 넣어 제목을 작성합니다. `##`, `###`으로 제목의 단계를 구분합니다.

```markdown
# 문서 제목
## 장 제목
### 세부 제목

빈 줄로 문단을 구분합니다.
```

문장 끝에 공백을 두 칸 넣으면 줄이 바뀝니다.  
이 문장은 같은 문단의 다음 줄입니다.

## 목록과 강조

- **굵게**: `**굵게**`
- *기울임*: `*기울임*`
- ~~취소선~~: `~~취소선~~`
- `코드`: 백틱으로 감싼 텍스트

1. 첫 번째 작업
2. 두 번째 작업
   - 세부 작업
   - 추가 설명

## 코드와 수식

```python
def average(values):
    return sum(values) / len(values)

scores = [85, 92, 88]
print(average(scores))
```

인라인 수식은 `$x^2$`, 별도 줄의 수식은 `$$`로 감쌉니다.

$$
f(x) = x^2 + 2x + 1
$$
