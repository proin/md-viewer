# 마크다운, 편안하게 읽기

폴더 안의 문서를 한곳에서 읽고, 필요한 내용을 바로 수정하십시오. 파일을 선택하면 미리보기가 먼저 열립니다.

> 문서에 집중하는 공간. 익숙한 마크다운으로 기록하고, 정돈된 화면으로 읽으십시오.

## 빠르게 시작하기

1. 왼쪽 위 **폴더 열기**를 눌러 문서 폴더를 선택합니다.
2. 파일 목록에서 `.md` 파일을 선택합니다.
3. **편집하기**를 눌러 내용을 수정한 뒤 **저장**을 누릅니다.

| 작업 | 사용 방법 |
| :--- | :--- |
| 문서 읽기 | 왼쪽 파일 목록에서 마크다운 파일 선택 |
| 문서 편집 | 상단의 **편집하기** 선택 |
| 변경 내용 저장 | **저장** 또는 <kbd>⌘</kbd> + <kbd>S</kbd> |
| 다른 앱에서 열기 | 상단의 **기본 앱으로 열기** 선택 |

## 코드도 선명하게

언어 이름을 지정하면 코드에 색상이 적용됩니다. 코드 오른쪽 위의 **복사**로 전체 코드를 복사할 수 있습니다.

```typescript
interface Document {
  title: string;
  content: string;
}

function openDocument(document: Document) {
  return {
    title: document.title,
    mode: "preview",
    content: document.content,
  };
}
```

## 할 일 정리하기

- [x] 폴더에서 문서 선택
- [x] 제목, 표, 코드 읽기
- [ ] 편집 모드에서 문장 추가
- [ ] 저장 후 다시 열기

**굵게**, *기울임*, ~~취소선~~, `인라인 코드`를 함께 사용할 수 있습니다. 더 많은 작성 예제는 [마크다운 작성법](./안내/마크다운%20작성법.md)에 있습니다.

## 문서 흐름 그리기

Mermaid 코드를 다이어그램으로 표시합니다. 그림 위의 **+**, **−** 버튼으로 크기를 조절할 수 있습니다.

```mermaid
flowchart LR
    A[폴더 열기] --> B[문서 선택]
    B --> C[미리보기]
    C --> D[편집]
    D --> E[저장]
    E --> C
```

## 수식 표현하기

문장 안의 수식 $E = mc^2$와 별도 줄에 배치한 수식을 모두 표시합니다.

$$
\bar{x} = \frac{1}{n} \sum_{i=1}^{n} x_i
$$
