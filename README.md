# Markdown Viewer

macOS에서 폴더 속 마크다운 문서를 읽고 편집하는 데스크톱 앱입니다.

## 사용 방법

1. `Markdown Viewer.app`을 실행합니다. 자주 사용하는 경우 응용 프로그램 폴더로 옮길 수 있습니다.
2. 상단의 **파일 열기**에서 `.md` 파일을 직접 선택하거나, **폴더 열기**로 파일 트리를 표시합니다.
3. 마크다운 파일은 읽기 화면으로 열립니다. Finder의 파일 또는 폴더를 앱 창에 끌어 놓아도 열립니다.
4. **편집하기**를 누르면 원문 편집기와 미리보기가 나란히 표시됩니다.
5. **저장** 또는 `⌘S`로 원본 파일에 저장합니다.
6. **기본 앱으로 열기**를 누르면 macOS에서 해당 파일에 지정한 앱이 실행됩니다.

파일 하나만 사용할 때는 폴더를 먼저 열 필요 없이 **파일 열기** 또는 `⌘O`를 사용합니다. 파일 선택 창에서 여러 문서를 선택하면 각각 탭으로 열립니다. 파일 이름 검색은 선택한 폴더의 하위 폴더까지 검색합니다. 마지막으로 사용한 폴더, 열린 탭과 선택한 탭은 다음 실행 때 복원됩니다.

폴더를 끌어 놓으면 왼쪽 파일 트리가 바뀌고, 마크다운 파일을 끌어 놓으면 해당 문서가 탭으로 열립니다. 여러 파일을 한 번에 놓아도 각각 열립니다. 기존 탭과 편집 내용은 유지됩니다.

이동되거나 삭제된 경로는 다시 선택할 수 있도록 알림을 표시합니다. 이전 폴더를 읽을 수 없어도 다른 마크다운 파일을 직접 열 수 있습니다.

## 탭과 파일 닫기

탭을 선택하면 해당 문서로 이동합니다. 같은 파일을 다시 열면 기존 탭으로 이동합니다. 문서마다 편집 내용, 실행 취소 기록, 커서와 스크롤 위치를 유지합니다.

탭 오른쪽의 **×** 또는 `⌘W`로 파일을 닫습니다. 편집한 탭을 닫을 때는 **저장하고 닫기**, **저장하지 않고 닫기**, **취소**를 선택합니다. 마지막 탭을 닫으면 시작 화면이 표시되고 폴더 트리는 유지됩니다. 닫은 탭은 다음 실행 때 다시 열리지 않습니다.

**저장**은 선택한 탭을 저장합니다. **파일 → 모두 저장**은 모든 탭의 변경 내용을 저장합니다. 앱을 종료할 때 **저장하고 종료**를 선택하면 모든 변경 내용을 저장한 뒤 종료합니다. 한 문서라도 저장하지 못하면 앱이 열린 상태로 유지됩니다.

## Finder에서 열기

마크다운 파일을 오른쪽 클릭한 뒤 **다음으로 열기 → Markdown Viewer**를 선택합니다. 목록에 없으면 **기타**에서 `Markdown Viewer.app`을 선택합니다.

항상 이 앱으로 열려면 파일의 **정보 가져오기 → 다음으로 열기**에서 **Markdown Viewer**를 선택하고 **모두 변경**을 누릅니다. 앱은 파일 연결 설정을 자동으로 변경하지 않습니다.

## 미리보기

- 제목·목차·목록·인용·링크·이미지
- 표·체크 목록·취소선
- 코드 구문 강조와 복사
- Mermaid 다이어그램과 확대·축소
- KaTeX 인라인 수식과 블록 수식
- 접기·펼치기를 포함한 안전한 HTML
- 문서에 연결된 로컬 이미지와 HTTPS 이미지

VS Code의 기본 마크다운 미리보기에서 제공하는 주요 문법을 구현했습니다. 앱의 색상과 도구 배치는 별도로 구성했으며 VS Code 확장은 실행하지 않습니다.

## 편집과 저장

- 마우스로 드래그하거나 `Shift`와 방향키로 글자를 선택합니다. 선택한 부분은 파란색으로 표시되며, 편집기 아래에 커서 위치·선택한 글자 수·줄 범위가 표시됩니다.
- 편집기 위의 **전체 선택**, **복사**, **잘라내기**, **붙여넣기** 버튼을 사용할 수 있습니다. 복사와 잘라내기 버튼은 선택한 내용이 있을 때 사용할 수 있습니다.
- 선택한 부분에서 오른쪽 클릭하면 편집 메뉴가 열립니다. `⌘C`·`⌘X`·`⌘V`도 사용할 수 있습니다. 붙여넣기는 선택한 부분을 바꾸고, 선택하지 않은 경우 커서 위치에 내용을 넣습니다.
- **실행 취소**·**다시 실행** 버튼으로 변경을 되돌릴 수 있습니다. **찾기** 또는 `⌘F`는 찾기·바꾸기 창을 엽니다.
- 편집한 탭을 닫거나 앱을 종료할 때 저장하지 않은 내용을 확인합니다.
- 다른 앱에서 변경한 파일은 읽기 화면에 자동으로 반영합니다.
- 편집 중 원본이 변경되면 알림을 표시하고 덮어쓰기를 차단합니다. 편집 내용을 복사한 뒤 문서를 다시 열어 합칠 수 있습니다.
- UTF-8 파일을 지원하며 기존 줄바꿈과 파일 권한을 유지합니다.
- 20MB 이하의 마크다운 파일과 40MB 이하의 로컬 이미지를 지원합니다.
- 로컬 이미지는 선택한 폴더 안에서, 파일 하나만 연 경우 해당 파일의 폴더 안에서 표시합니다.

## 소스 실행

`.nvmrc`에 기록된 Node.js 26.7.0을 사용합니다. Node.js 24 또는 26 이상에서도 실행할 수 있습니다.

개발 실행 전에는 실행 중인 Markdown Viewer를 종료합니다.

```sh
git clone https://github.com/proin/md-viewer.git
cd md-viewer
npm ci
npm start
```

```sh
npm test        # 파일 처리와 마크다운 렌더링 검사
npm run test:e2e # 실제 데스크톱 앱 동작 검사
npm run package # Apple Silicon용 macOS 앱 생성
```

`sample-docs/시작하기.md`에 표·코드·다이어그램·수식·이미지 예제가 있습니다.

## 개발과 업데이트

GitHub 저장소는 `proin/md-viewer`입니다. 저장소를 내려받은 폴더에서 수정·검사·빌드를 진행합니다.

1. `src/`에서 화면·편집기·미리보기를, `electron/`에서 파일 처리와 macOS 기능을 수정합니다.
2. `npm start`로 앱을 실행하여 변경 내용을 확인합니다.
3. `npm test`와 `npm run test:e2e`를 실행합니다. `test:e2e`는 빌드 후 실제 앱 검사를 실행합니다.
4. 배포할 때 `package.json`과 `package-lock.json`의 버전을 함께 변경하고 `CHANGELOG.md`에 변경 내용을 기록합니다. `npm version patch --no-git-tag-version`으로 수정 버전을 올릴 수 있습니다.
5. `npm run package`를 실행합니다. 새 앱은 `release/mac-arm64/Markdown Viewer.app`에 생성됩니다. 실행 중인 앱을 종료한 뒤 새 앱으로 교체합니다.
6. 작업이 끝나면 Git에 변경 내용을 기록합니다.

| 폴더·파일 | 용도 |
| --- | --- |
| `src/` | 앱 화면, 편집기, 미리보기 |
| `electron/` | 파일 열기·저장, 메뉴, 클립보드 |
| `tests/` | 파일 처리·미리보기·앱 동작 검사 |
| `sample-docs/` | 기능을 확인할 예제 문서 |
| `build/` | 앱 아이콘 |
| `dist/` | 앱 화면 빌드 결과 |
| `release/` | 배포용 앱 |
| `artifacts/screenshots/` | 검사 중 저장한 화면 이미지 |

의존성 폴더, 빌드 결과, 검사 결과, 로그, `.env`·`.npmrc` 등 로컬 설정과 인증서 비밀키는 Git 기록에서 제외합니다. 의존성은 `package-lock.json`에 기록된 버전으로 설치합니다. 환경변수 예시를 공유하려면 실제 비밀값을 제거한 `.env.example`을 사용합니다.

`npm run dev`는 화면 개발용 Vite 서버를 실행합니다. 파일 열기와 저장은 Electron 앱에서 동작하므로 일반 사용·검사에는 `npm start`를 사용합니다.

## 구성

React·TypeScript·CodeMirror로 화면과 편집기를, Electron으로 파일·폴더 및 macOS 기능을 구현했습니다. markdown-it·highlight.js·KaTeX·Mermaid·DOMPurify가 문서 렌더링을 처리합니다. 문서의 스크립트와 실행 가능한 HTML은 차단합니다.

앱은 로그인이나 서버 없이 실행됩니다. 문서에 HTTPS 이미지가 있으면 해당 이미지 서버에 접속합니다.
